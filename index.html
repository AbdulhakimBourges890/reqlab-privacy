Privacy Policy

ReqLab – API Testing Tool

Last updated: November 22, 2026

1. Introduction

Welcome to ReqLab. ReqLab is a tool designed to help users create, send, and inspect HTTP and HTTPS API requests.

This Privacy Policy explains how information is handled when you use the ReqLab mobile application.

By using ReqLab, you acknowledge the practices described in this Privacy Policy.

2. Information We Collect

ReqLab does not require users to create an account or provide personal information such as their name, phone number, or email address to use its core functionality.

When using the application, users may enter or process information such as:

  • API endpoint URLs.
  • HTTP methods and request parameters.
  • Request headers and authorization tokens.
  • Request body content.
  • API response data and status information.

This information is provided by the user as part of API testing activities. It may contain personal or sensitive information depending on what the user chooses to submit.

3. API Requests and Third-Party Servers

ReqLab allows users to send API requests to servers and endpoints of their choice.

When a request is sent, the information included in that request, such as its URL, headers, authorization credentials, and body, is transmitted to the destination server.

Important: The destination server may receive, collect, store, or otherwise process the information you send according to its own policies and practices.

ReqLab does not control third-party API servers. Users should review the privacy and security practices of any server they communicate with.

Do not send passwords, access tokens, personal information, or other sensitive data to an endpoint unless you trust that endpoint and understand how it handles the information.

4. How Information Is Used

Information entered into ReqLab is used to provide the application's API testing functionality, including:

  • Creating and sending API requests.
  • Receiving and displaying API responses.
  • Displaying response status codes and related information.
  • Supporting the application's core features.

5. Data Sharing

ReqLab does not sell users' personal information.

API request information is sent to the destination server selected by the user when the user chooses to send a request. That server may independently process or retain the information.

Users are responsible for choosing appropriate and trusted API endpoints.

6. Data Storage and Retention

Information may be processed by the application while performing API testing operations.

Any information retained by a destination API server is governed by that server's own privacy policy and retention practices.

7. Internet Permission

ReqLab requires internet access to send HTTP and HTTPS requests to API endpoints selected by users and to receive their responses.

The application uses this permission to provide its core API testing functionality.

8. Third-Party Services and External Links

The application may provide links to external websites or services, such as developer resources or project pages.

External websites are operated independently and may have their own privacy policies. ReqLab is not responsible for their content, practices, or data handling.

9. Data Security

Users should take care when entering sensitive information into API requests, particularly authorization tokens, passwords, and private credentials.

Users should use HTTPS endpoints whenever possible and avoid sending confidential information to untrusted servers.

No method of electronic transmission or storage can be guaranteed to be completely secure.

10. Children's Privacy

ReqLab is not specifically designed to collect personal information from children.

We do not knowingly collect personal information from children through the application.

11. Your Choices and Responsibilities

You are responsible for the information you enter into API requests and for selecting the servers to which that information is transmitted.

You should avoid including sensitive personal information in requests unless it is necessary and you trust the receiving service.

12. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the application or its practices.

Any updates will be published on this page. The date at the top of the page will be revised when changes are made.
